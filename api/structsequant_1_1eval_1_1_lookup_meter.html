struct LookupMeter¶

diagnostic (analysis-only, off by default): counts and times every cache_map_.find(key) performed by CacheManager. Each such find runs TreeNodeEqualityComparator on any bucket match &#8212; a recursive structural compare of the whole subtree (memoized-hash O(1) per node

  • linear bliss ConstGraphCmp on the connectivity graph, recursed into left/right). This meter isolates the aggregate wall time that lookup costs, so a schedule that issues more read-from-home lookups (ordered) can be compared against one that inlines (forest). Env gate SEQUANT_UT_LOOKUP_METER; when unset every site is a no-op passthrough and the eval path is left untouched. Single-threaded runs only.
