class IntermediateNamePool¶

Keeps track of the names of intermediates and how often they are currently in use. Names that are no longer in use are handed out to new intermediates of compatible shape and fresh names are generated such that they don’t collide with any reserved or previously used name.

Tensors are identified by their label and their block, i.e. tensors with the same label but different blocks refer to different objects. Hence, the same label can be handed out for tensors of different blocks.

Returns:

A label that has not been reserved and that, together with the block of candidate, has not been known to this pool before. The respective object is marked as being in use.

template<typename T>
inline Allocation lowest_available(std::wstring_view basename, const T &candidate, const std::function<bool(const T&)> &acceptable = {}) const¶

Determines the first label (in the order of the pool’s LabelGenerator) that, together with the block of candidate, refers to an object that is not in use and for which acceptable (if provided) returns true. Contrary to fresh_label and acquire, the respective object is not marked as being in use (see occupy).

Parameters:

  • basename – The basename to derive labels from

  • candidate – The Tensor or Variable the label is meant for

  • acceptable – Predicate invoked with candidate relabeled to the label under consideration

inline std::optional<RecycledTensor> acquire(const Tensor &candidate, ShapeCompatibility compatibility, const std::function<bool(const Tensor&)> &acceptable = {})¶

Searches for an object that is not in use, whose block is compatible with candidate under compatibility and for which acceptable (if provided) returns true. Of all such objects, the one that has become known to this pool first is chosen and marked as being in use.

Returns:

candidate relabeled (and rearranged) to the recycled name, or std::nullopt if no suitable name is available
