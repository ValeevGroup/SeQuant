Detailed Description
--------------------

ranks (``type_rank``) of SeQuant's own :ref:`exhale_class_classsequant_1_1_expr` types; Expr::operator< orders unlike types by rank first, so this is their order. Spaced so that a new type can be inserted between them; types of Expr::default_type_rank sort between ``power`` and ``boperator``.
