Namespace sequant::eval::rec
============================


One use-site of a value, kept alongside the folded ``ValueCell``. Inline capacities of the per-node, per-occurrence and per-value records below (``NodeRec``, ``OccurrenceRec``, ``ValueCell``). There is one record per forest node, so the records are sized for the common case rather than boost::container::small_vector's default of 8 elements: an ``Index`` is 232 bytes, so the default made an ``Index`` list 1.9 KB and a ``ValueCell``, which inlined 8 occurrence records, 102 KB  about 1.5 GB of mostly unused inline storage for the 2550-term UCC energy of h2o+. An ``Index`` list holds up to 3 inline (a CSV-CCSDT residual's occupied indices); the operand, slot and loop lists 2; longer lists spill to the heap.
