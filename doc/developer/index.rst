Developer documentation
=======================

Documentation for SeQuant contributors: how the documentation itself is built and extended, how expression types are
identified and ordered, and the internal architecture of Wick's theorem, symbolic differentiation, tensor-network
canonicalization, the cost-based optimizer, the batched evaluation engine, and the code-generation/export framework. This
complements, rather than repeats, the :doc:`User Guide </user/guide/index>`, which covers the public API a library user
calls.
